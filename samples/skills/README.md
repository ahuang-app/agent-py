# 对话 Skill 测试样例

本目录存放用于人工测试"渐进式 Skill"功能的 `SKILL.md` 样例。每个子目录对应一个 Skill，
上传时**选择其中的 `SKILL.md` 文件本身**（界面要求文件名严格为 `SKILL.md`）。

## 样例与验证要点

| 目录 | 场景 | 上传后如何验证生效 |
|------|------|--------------------|
| `latex-writing/` | 数学公式排版 | 勾选后提问"用行内公式和块级公式分别写出 O(N log N) 和高斯求和"，回答应出现渲染后的公式而非 `$...$` 原文 |
| `code-review/` | 代码评审 | 勾选后粘贴一段有缺陷的代码请求评审，回答应严格呈现"评审结论 / 问题清单 / 亮点"三段结构 |
| `sql-troubleshooting/` | 慢 SQL 排查 | 勾选后描述"数据库很慢"，回答应从"第 1 步：明确现象"开始，一次只推进一个步骤并反问 |
| `incident-brief/` | 故障通报起草 | 勾选后提供一次演练故障并要求起草通报，缺失信息应出现在"信息缺口"而不是被编造 |

## 上传与生效流程

1. 进入 `/chat`，展开右侧「Skill 设置」。
2. 上传某个 `SKILL.md`（单文件 ≤ 64 KB，UTF-8 Markdown）。
3. 勾选要启用的 Skill，点击「保存使用的 Skill」。
4. 初始上下文只注入 `name` 与 `description`；模型认为需要时才会通过 `load_skill` 工具加载正文，
   因此可在"工具调用"折叠区看到 `load_skill` 的调用记录，即验证了渐进加载语义。

## 注意

- 这些样例仅用于功能验证，不是产品功能的一部分；按用户（user）维度上传后仅本人可见。
- 测试完成后可在界面中删除对应 Skill，避免影响日常对话风格。
